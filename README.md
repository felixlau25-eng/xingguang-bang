# 星光榜

課堂學生獎勵計劃積分榜。老師按表現加上小星星，同學只可查看自己的進度。每 10 顆小星星會換成 1 顆大星星。

加星來源：

- 完成一頁補充練習
- 完成一次默書或試默
- 上課表現良好

## 使用

- **同學**：打開網址，搜自己的名字，點卡片看大星星、小星星進度。不能改分數。
- **老師**：按「老師入口」，輸入密碼後可以加星、新增同學、改班名。預設密碼是 `2468`，登入後請立即更改。

資料會儲存在資料庫，下次打開仍然在。

## 本倉庫

這個 GitHub 倉庫存放星光榜的程式碼，方便備份、之後改功能。要讓同學在手機或電腦打開使用，需要把網站發佈到網上。
